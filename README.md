# claude-buddy

A cute little buddy that walks right to left above the Claude Code prompt, stops to wave, dance, nap or send hearts, then carries on. It runs faster while Claude is working. `/buddy` hides or shows it.

## Install

```
/plugin install buddy --marketplace hokamsingh/ccbuddy
```

## Options

Set in `/config` (or `pluginConfigs` in settings): `color`, `speed` (slow, normal, fast), `rows` (compact takes one row, tall takes two), and `showWhileWorking`.
